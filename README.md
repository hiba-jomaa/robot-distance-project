# Robot Distance Project

## Project Description

This project reads distance values and decides whether the robot should STOP, SLOW, or MOVE.

## Requirements

- Python 3
- VS Code

## Files

- `robot.py`: main program
- `README.md`: project instructions

## How to Run

```bash
python3 robot.py
```

## Example Output

```text
Distance: 0.4 m
Robot action: STOP
```
